# SoftGrowTech Dashboard UI

## Project Overview

A modern and responsive dashboard interface designed as part of my UI/UX internship at SoftGrowTech.

The dashboard focuses on clear navigation, visual hierarchy, data visualization, and a consistent design system.

## Features

- Modern sidebar navigation
- Responsive desktop layout
- Statistics cards
- Project analytics
- Progress visualization
- Team collaboration section
- Project tracking
- Consistent color system
- Clean and accessible interface

## Design Tools

- Figma
- UI/UX Design
- Auto Layout
- Components & Variants
- Responsive Design
